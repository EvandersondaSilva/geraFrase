# Gerador de Frases | React + TypeScript

Este projeto é uma aplicação simples desenvolvida em **React** com **TypeScript** que permite ao usuário selecionar categorias e gerar frases aleatórias. As categorias disponíveis incluem motivação, bom dia e boa noite.

## 🚀 Tecnologias utilizadas
- React
- TypeScript
- CSS
- Vite 

## 📌 Funcionalidades
- Seleção de categorias
- Exibição dinâmica das frases
- Botão para gerar uma frase aleatória
- Destaque visual da categoria selecionada

## 📷 Interface
A interface conta com:
- Logo centralizada
- Botões de categorias
- Botão principal para gerar frase
- Exibição da frase escolhida
